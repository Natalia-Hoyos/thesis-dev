# Gladys

Gladys is a voice-based social companion for older adults. It holds spoken conversation and runs cognitive games, including trivia, guess-the-song and a crossword displayed on a connected screen.

The system was developed as part of an Honours thesis in Mechatronics Engineering at the Queensland University of Technology (QUT), in collaboration with [Stones Corner AI](https://www.stonescorner.ai). Gladys runs on the company's MyCo robot, which supplies the microphone, speaker and face display. Gladys supplies the voice and the conversation.

The thesis research question was: how can a social companion robot be designed and implemented to deliver evidence-based, cognitive health-supporting activities to older adults through natural conversation and interactive games?

## Features

**Conversation.** Gladys engages in open conversation, asks participants about their families and past experiences, and responds to what they say. Replies are generated by a language model and are not scripted.

**Games.** The following activities are delivered by voice:

- Trivia, with a bank of 100 easy and 100 hard questions. The system tracks questions already used, so none repeats within a session.
- Guess-the-song, drawn from a fixed song bank.
- A crossword, displayed on a screen through a local web server. Gladys reads the clues aloud, selects a puzzle the participant has not yet played and saves progress between sessions.

**Planned work.** Reminiscence therapy and spaced retrieval, in which Gladys returns to a participant's stories in later sessions, are proposed as the next stage. They are not implemented in the current code.

## System Design

Gladys is a voice agent built on [LiveKit Agents](https://github.com/livekit/agents) in Python. It runs as a worker on a laptop and registers with a LiveKit Cloud project. When the MyCo robot is switched on, it joins a room in that project and LiveKit dispatches the worker to it. Audio from the robot's microphone is passed to Gladys for processing, and the generated speech is played through the robot's speaker.

| Stage | Component |
|---|---|
| Voice activity detection | Silero, with LiveKit's multilingual turn detection model |
| Speech to text | Deepgram Nova-3 |
| Response generation | GPT-4.1-mini |
| Text to speech | Cartesia Sonic-3 |

The language model is accessed through its own layer, so a different provider can be substituted with small code changes.

### Game content

Game content is held in fixed banks, and game logic is implemented as deterministic Python modules. The language model does not write the questions. Its role is limited to conversational delivery: asking questions, responding to answers, offering encouragement and moving between activities. This approach prevents the model from repeating themes, and it allows crossword grids to be checked in advance so that no unintended letter runs occur.

Games read from plain content files. New questions and puzzles can therefore be added without changing the conversation code.

## Installation

The following are required:

- Python 3.9 or later
- A LiveKit Cloud project
- API keys for Deepgram, OpenAI and Cartesia
- A MyCo robot, or another LiveKit client able to join a room and send audio

Install the dependencies, set the API keys as environment variables and start the agent worker. Refer to the LiveKit Agents documentation for the worker commands. Connecting a MyCo robot to a LiveKit project requires configuration by Stones Corner AI. Without one, the agent can be tested from any other LiveKit client.

## Evaluation

Gladys was tested at Blue Care's day respite centre in Gatton, Queensland, with four cognitively healthy adults aged 65 and over. Each participant completed one session of about 20 minutes. Data were collected through an emoji-based mood activity before and after each session, short interviews, observation notes and a researcher debrief. The study was approved by QUT's University Human Research Ethics Committee (approval ID 11365). Responses were analysed using reflexive thematic analysis.

The main findings were:

- Conversation took over from games. Participants spent more of their sessions discussing their families and past work than playing trivia.
- Participants were impressed that Gladys followed the conversation, but none said they would use it again.
- All four participants selected a positive mood after the session.
- Three faults disrupted otherwise natural conversation: trivia sometimes failed to recognise correct answers, Gladys interrupted participants who paused mid-story, and head tracking failed in one session.

The sample was small and drawn from a single site, and no cognitive outcomes were measured. The findings are a first indication of how older adults respond to the system. They do not show that Gladys supports cognitive function. The final report describes the limitations in full.

## Privacy

While running, Gladys sends speech to LiveKit, Deepgram, OpenAI and Cartesia. In the trial, Deepgram was configured to discard audio after transcription, and OpenAI requests were configured not to store completions. OpenAI's standard abuse-monitoring retention of up to 30 days still applied. No session logs were kept. Anyone deploying Gladys with real users should inform them of this before use.
